读图结论

这张图同时保留系统级对比和实验边界，不把跨硬件差异归因给单一框架。

01 · AFFINITY

c48 从左下跃迁到右上

开启 Session Affinity 后，Output throughput 提高 92.0%，P90 Interactivity 提高 265.9%。核心机制是多轮会话保持在同一 DP rank，恢复 prefix KV cache locality。

02 · LOCAL FRONTIER

c64 / c96 是更实用的选择

c64 保持 30.09 tok/s/user；c96 将输出提高到 247.38 tok/s/chip。c128 达到最高吞吐，但从 c96 到 c128 的 Total throughput 仅增 10.81%。

03 · B200 TARGET LINE

B200 高并发扩展更强

同为 c128，vLLM B200 达到 403.29 tok/s/chip、32.73 tok/s/user；DEP 为 279.94、16.41。硬件、MoE backend、调度与 KV offload 均不相同。

Decision guide

选 c64：P90 Interactivity 需保持 ≥30；选 c96：追求更高吞吐的综合折中；选 c128：只追求本机最大输出吞吐，并接受交互性下降与边际收益收窄。

口径与边界

METRIC

为什么使用 Output throughput

AgentX 长上下文的大量输入 token 来自 prefix-cache read；Total throughput 会把缓存输入计入，因此主图采用更接近 Decode 能力的 Output tok/s/chip。

POWER

Utility MW 是计算值

COMPARABILITY

B200 只作为目标线

模型、AgentX workload、MTP-3 和 DPA8 + EP8 大拓扑对齐；但硬件、EPLB、MoE transport、shared expert、调度和 KV offload 不完全相同。
